# M30 filtered selective-search quality

The [raw 250,000-row run](m30/filter-selectivity-250k/run.json) measures the first
200 SIFT1M queries at `k=10` against the first 250,000 SIFT1M base vectors
(128 dimensions, squared Euclidean distance). The base prefix SHA-256 is
`fab6b3f6c68d8bca09c72b0ee84a8126b80aebc635765fb52c0ab3efbda51960`.
The probe builds a fresh `LocalStore` segmented namespace with 100-row requests,
the M24 acceptance loader's seal/consolidation maintenance schedule, and
`resident_filter = (cohort, one-percent)`. The resulting root has 20 runs,
1,482 blocks, and four tail objects. There is no block cache. The exact oracle
scans the loaded base vectors in f64 for each query and predicate, breaking
distance ties by ID. Recall is the fraction of exact top-10 IDs returned;
the fifth percentile is the tenth lowest per-query recall among 200 queries.
The short-result fraction counts queries returning fewer than ten neighbors.
The run used macOS (`Darwin arm64`) with Rust 1.98.1.

`serving` uses the M21 serving budget of 12 routed blocks, 8 range requests,
and 1 MiB of range bytes. `2x` and `4x` scale all three limits together.
The five equality predicates are deterministic ID assignments:

| Predicate | Assignment | Matching rows | Selectivity | Mode |
|---|---|---:|---:|---|
| `cohort=one-percent` | `id % 100 == 0` | 2,500 | 1% | Declared resident |
| `half=yes` | `id % 2 == 0` | 125,000 | 50% | Post-filter |
| `tenth=yes` | `id % 10 == 0` | 25,000 | 10% | Post-filter |
| `pct=yes` | `id % 100 == 1` | 2,500 | 1% | Post-filter |
| `permille=yes` | `id % 1000 == 7` | 250 | 0.1% | Post-filter |

## Quality policy for this layout and budget

At the serving budget, the measured post-filter configuration fails the
mean recall@10 >= 0.90 and P5 recall@10 >= 0.80 gates for every nonresident
predicate. With routed keys, the 50% predicate passes both gates (0.9210,
0.80); the 10%, 1%, and 0.1% predicates meet P5 0.80 but fall short of the
mean gate (0.8905, 0.8660, and 0.8395). At 2x, all four measured routed
predicates reach 1.0000 mean and P5 recall with ten results per query. The
declared resident 1% predicate remains exact at every budget. These values
establish policy only for this layout, dataset and read budgets. The probe
measures quality and result completeness, not latency or remote traffic.

## M30 routed-key comparison

The [paired run](m30/filter-routing-250k/run.json) repeats the same 250,000-row
layout and 200 queries with `routed_keys = [half, pct, permille, tenth]` in a
second fresh namespace. Both configurations have 20 runs, 1,482 blocks, four
tail objects, no block cache, and the same input SHA-256 above. Each cell is
mean recall@10 / P5 recall@10; all values use the same exact filtered oracle.

| Predicate | Budget | Post-filter | Routed |
|---|---|---:|---:|
| 50% `half` | serving | 0.6510 / 0.30 | 0.9210 / 0.80 |
| 50% `half` | 2x | 0.9680 / 0.80 | 1.0000 / 1.00 |
| 50% `half` | 4x | 1.0000 / 1.00 | 1.0000 / 1.00 |
| 10% `tenth` | serving | 0.2455 / 0.00 | 0.8905 / 0.80 |
| 10% `tenth` | 2x | 0.4670 / 0.20 | 1.0000 / 1.00 |
| 10% `tenth` | 4x | 0.7995 / 0.50 | 1.0000 / 1.00 |
| 1% `pct` | serving | 0.1115 / 0.00 | 0.8660 / 0.80 |
| 1% `pct` | 2x | 0.2140 / 0.00 | 1.0000 / 1.00 |
| 1% `pct` | 4x | 0.3870 / 0.10 | 1.0000 / 1.00 |
| 0.1% `permille` | serving | 0.0430 / 0.00 | 0.8395 / 0.80 |
| 0.1% `permille` | 2x | 0.1040 / 0.00 | 1.0000 / 1.00 |
| 0.1% `permille` | 4x | 0.2380 / 0.00 | 1.0000 / 1.00 |

Charged sketch bytes are 28,793,952 without routed keys and 30,136,476 with
them, an increase of 1,342,524 bytes (4.66%). The 0.1% routed predicate
still returns fewer than ten results for 52% of serving-budget queries; at 2x
all measured routed queries return ten. The resident predicate has 1.0000
recall and ten results at each budget in both configurations.

Reproduce the paired run with a fresh output directory:

```sh
cargo run --offline --release --example m30_filter_probe -- /private/tmp/glider-m21-data/sift1m_base_250000.fvecs /private/tmp/glider-m21-data/sift1m_query.fvecs 250000 benchmarks/m30/filter-routing-250k > benchmarks/m30/filter-routing-250k/run.json
```
