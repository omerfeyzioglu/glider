# M11 selective exact reads

Revision `38f2e72a08bbf34ff1c58ef5d39cfebf84de621e`, clean source tree.
[Raw report](m11/minio.json) includes all samples, source hash and environment.
Apple M4, macOS, Rust 1.98.1 release, disposable loopback MinIO; same M8
2,000 rows, 64 dimensions, seed 42, 1,000 independent queries, k=10,
`selected=true` every 100th ID, 128 KiB chunks. Setup and resident exact
oracle are untimed; each measured answer is compared with that oracle.
Tests also use independently specified answers, both metrics and ties.

| Query path | p95 ms | GET/query | Logical bytes/query |
|---|---:|---:|---:|
| Filtered full scan | 33.803 | 12 | 1,492,616 |
| Filtered resident posting | 0.001667 | 0 | 0 |
| Unfiltered ordinary reader | 34.492 | 12 | 1,492,616 |
| Unfiltered posting reader | 36.049 | 12 | 1,492,616 |

Nonselective p95 change is +4.51%, below the 20% budget. Process lifetime
peak RSS is 44.89 MiB including setup, oracle and both readers, below 64 MiB.
The filter matches 20 rows spread across 11 of 12 chunks: chunk summaries
alone would still exceed four GETs. The chosen posting reuses the mandatory
validated open scan, adds no writes and has an explicit 64-row cap here.
Opening still validates all authoritative chunks. This is a bounded hot-filter
optimization, not a general metadata index or a larger-dataset memory claim.

Tests cover both metrics, exact ties, contradictory/missing predicates,
updates/deletes/new IDs, compaction and reopen, an older compacted root plus a
newer checkpoint, posting-cap rejection, and missing selected chunks.
No derived persistent state can become stale or block recovery.

The full comparison exposed idle S3 HTTP tasks suspended by the old private
current-thread runtime. M10a keeps one Tokio worker active; its deterministic
regression test fails under the old runtime. The corrected full comparison
completed 36,000 GETs without adding retries.

Reproduce: `python3 tools/m11_benchmark.py target/m11.json --full`.
Default short mode diagnoses request counts; only full mode supplies 1,000
samples for every p95 comparison. These are loopback single-run measurements,
not a production remote-service tail guarantee.
