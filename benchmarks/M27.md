## Finding

All 1,200 acknowledged write batches published one log object each because
`Profiled` inherited the admission engine's per-request fallback for grouped
writes. Admission could still collect concurrent writes, then charge every
member the full time for several sequential PUTs. This invalidates the old
inference that the arrival pattern provided no groups. The PUT reduction in
this run came from fewer pack and root publications. Write execution and
cold-query p95 rose against M24 but stayed within their gates. The corrected
wrapper and a local measurement are documented in `M31.md`; the M27 4 PUT/s
target still needs a MinIO rerun.
